# Sims 4 Package Builder\n\nThis component is the production-side milestone for CC Forge.\n\n## Goal\nTurn a CC Forge garment specification into a real Sims 4 DBPF package.\n\n## Stages\n1. Select an internal CC Forge-owned clothing base mesh matching the garment body type.\n2. Generate/adapt UV texture data from the Maxis Match design.\n3. Generate valid GEOM resources for required LODs.\n4. Generate CASP resources referencing the GEOM and texture resources.\n5. Assemble all resources into a DBPF 2.x package.\n6. Validate resource types, instance references, sizes and package readability.\n7. Return the `.package` only after validation succeeds.\n\n## Important\nThe browser and Cloudflare Worker should not pretend to create a playable package. Full mesh/GEOM work requires a server-side or local build environment capable of Sims 4 resource processing.\n\nThe first shippable version should use CC Forge-owned template meshes rather than claiming arbitrary AI-generated geometry is already game-ready. The AI garment specification controls the selected template, texture design and CAS configuration.\n\n## API contract\nInput: `garmentSpec`, generated texture, project metadata.\nOutput on success: `package`, `filename`, `validation`.\nOutput on failure: `error`, `stage`.\n\nNo fake `.package` files.
