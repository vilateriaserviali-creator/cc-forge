# CC Forge — Web MVP

Первый браузерный MVP сайта для создания CC для The Sims 4.

## Запуск
Откройте `index.html` в браузере. Никакого сервера для этой версии не требуется.

## Что уже работает
- адаптивная тёмная страница;
- загрузка изображения;
- drag & drop;
- предпросмотр и удаление изображения;
- выбор категории;
- выбор стиля и возраста;
- поле описания;
- демонстрационное создание проекта.
